Working on this assignment gave me a much better understanding of how a Django project is organized and how different parts work together to build a REST API. The hardest part for me was figuring out the best way to choose the right shipping box because there were several possible approaches. While testing my code, I noticed that my initial logic would return a successful response even when no valid product information was provided, which made me realize how important proper validation is. I also ran into a few issues, like forgetting to update the Django settings file and making some simple typo-related mistakes, but fixing them helped me understand the project better. Using Postman to test the API made it much easier to check different scenarios and confirm that the responses were correct. Writing unit tests also showed me why it's important to test the application after making changes instead of assuming everything still works. Another thing I learned was that keeping the business logic separate from the API views makes the code cleaner and easier to maintain. If I were to do this project again, I would spend more time researching different algorithms for selecting the most suitable box instead of mainly relying on volume and weight. Overall, this assignment improved my debugging skills and made me much more confident in building and testing Django REST APIs.
